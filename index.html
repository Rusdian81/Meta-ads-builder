LP Forge

Analisa gaya visual dari gambar referensi, lalu tempa jadi prompt JSON siap pakai untuk tiap section landing page — background image prompt + skema text-overlay.

v1 · client-side only
API key tidak pernah disimpan/di-upload
★

Panel Admin — Kelola User

Tambah, reset password, atau hapus user yang boleh pakai tool ini. Perubahan langsung berlaku, tanpa perlu buka Vercel.
01

Koneksi Gemini

Dipakai untuk analisa gambar (vision) dan generate JSON per section (text).
Disimpan hanya di memori tab ini selama halaman terbuka. Refresh = hilang.
Ganti kalau model ini sudah deprecated/diganti Google. Model harus mendukung input gambar.
02

Analisa Gambar Referensi

Upload contoh visual LP/produk yang mau ditiru gaya-nya (bukan tulisannya, tapi warna, komposisi, mood, treatment gambar).
03

Data Produk & Copy

Konten mentah. Makin lengkap, makin tajam hasil JSON per section-nya.
Dipakai supaya istilah, framing, dan warna default menyesuaikan produk — bukan otomatis kebawa gaya herbal.
Pakai Style Profile + Nama/Tagline/Harga di atas. Hasilnya tetap bisa diedit manual di bawah.
⚠️ Kalau kolom ini diisi otomatis oleh AI, itu placeholder buat cek layout — wajib diganti testimoni asli dari pembeli sebelum landing page dipublikasikan. Testimoni palsu berisiko melanggar aturan perlindungan konsumen.
Dipakai tool ini hanya untuk mengingatkan area penempatan di section Form. Tempel manual ke HTML LP final kamu nanti.
04

Generate JSON per Section

Tiap kartu = satu prompt JSON siap copy ke image-gen + overlay renderer kamu.
Lihat skema JSON overlay-engine (referensi field)
